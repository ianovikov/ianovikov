# ERD - Цифровой онбординг

## Что это
ER диаграмма для 4 таблиц, лежащих в основе SQL-кейсов в [`06-sql-portfolio`](../SQL).

## Структура
- **users** - клиенты 
- **applications** - заявки на онбординг 
- **verification_checks** - отдельные проверки внутри заявки 
- **products** - выданные продукты 

Связи: один клиент может подать несколько заявок; одна заявка проходит несколько проверок и может завершиться выдачей продукта.
