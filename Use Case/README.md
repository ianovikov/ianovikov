# Use Case диаграмма — Цифровой онбординг

## Что это
UML Use Case диаграмма системы цифрового онбординга: 8 сценариев (UC-01–UC-08), 4 актора (Клиент, Оператор бэк-офиса, Риск-менеджер, Администратор) и 3 внешние системы (Госуслуги Биометрия, СМЭВ/МВД, АБС/Процессинг).

## Что показано
- Клиент инициирует регистрацию, выбирает канал верификации (ЕБС либо паспорт + селфи), заполняет анкету и подписывает документы
- Связи `<<include>>` — обязательные подпроцессы (например, открытие счёта включает обращение к АБС/Процессингу)
- Связь `<<extend>>` — заявка может уйти на ручную проверку (UC-06) как расширение основного потока
- Отдельные акторы для операционных ролей: ручная проверка, рассмотрение высокорисковых заявок, администрирование справочников
