# Use Case диаграмма - Цифровой онбординг

## Что это
Use Case диаграмма системы цифрового онбординга: 8 сценариев, 4 актора и 3 внешние системы.

## Что показано
- Клиент инициирует регистрацию, выбирает канал верификации, заполняет анкету и подписывает документы
- Связи `<<include>>` - обязательные подпроцессы (например, открытие счёта включает обращение к АБС/Процессингу)
- Связь `<<extend>>` - заявка может уйти на ручную проверку, как расширение основного потока
- Отдельные акторы для операционных ролей: ручная проверка, рассмотрение высокорисковых заявок, администрирование справочников
