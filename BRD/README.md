# Business Requirements Document — Цифровой онбординг

## Что это
Демонстрационный BRD для вымышленного проекта «Цифровой онбординг новых клиентов банка» — полностью удалённое открытие счёта и выпуск виртуальной карты без визита в отделение.

## Что внутри
- Бизнес-цели и scope проекта
- 21 функциональное и 10 нефункциональных требований
- 8 бизнес-правил (BR-01–BR-08)
- 2 детализированных Use Case (основной и альтернативный сценарий верификации)
- Матрица трассировки: цели → требования → критерии приёмки
- Требования к персональным данным по 152-ФЗ

## Инструменты
Документ оформлен по стандартной структуре BRD (аннотация → цели → scope → требования → риски → критерии приёмки), с матрицей трассировки для контроля покрытия целей требованиями.
