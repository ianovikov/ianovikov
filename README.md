## Пет-проект

Это пет-проект, показывающий полный аналитический цикл - от бизнес-требований до API-контракта и SQL-аналитики - на примере системы полностью удалённого открытия банковского счёта.

| Папка | Артефакт | Что показывает |
|---|---|---|
| [`BRD`](./BRD) | Business Requirements Document | Бизнес-цели, scope, 21 функц. + 10 нефункц. требований, риски, критерии приёмки |
| [`Use Case`](./Use%20Case) | UML Use Case диаграмма | Акторы, сценарии, связи |
| [`BPMN`](./BPMN) | BPMN 2.0 схема процесса | Дорожки по ролям, параллельные проверки, бизнес-правила прямо на схеме |
| [`ERD`](./ERD) | ERD базы данных | Структура таблиц и связи между ними |
| [`API`](./API) | OpenAPI 3.1 спецификация | REST-контракты для регистрации, верификации, открытия счёта |
| [`SQL`](./SQL) | Интерактивные SQL-кейсы | 6 запросов  с реальным выполнением в браузере |
| [`Prototypes`](./Prototypes) | Прототипы экранов | 3 прототипа ключевых экранов |

### Суть проекта

Все артефакты связаны одной сущностью - заявкой на онбординг: **BRD** описывает требования > **BPMN** показывает процесс > **Use Case** детализирует сценарии взаимодействия > **ERD** фиксирует структуру данных > **API-спека** формализует контракт между системами > **SQL-кейсы** показывают, как эти данные анализируются после запуска.
