# BPMN-схема — Цифровой онбординг

## Что это
Схема бизнес-процесса в нотации BPMN 2.0 с тремя дорожками (пулами) по ролям: Клиент, Система онбординга, Бэк-офис.

## Что показано
- Оба канала верификации: через ЕБС (Госуслуги Биометрия) и через паспорт + видео-селфи с распознаванием и проверкой в СМЭВ (МВД)
- Параллельные шлюзы для одновременных автоматических проверок (данные МВД + проверка по перечням 115-ФЗ)
- Бизнес-правило BR-08 отмечено прямо на схеме: не более 3 попыток liveness-проверки
- Ветка ручной проверки заявки бэк-офисом при сомнительном результате скоринга
- Финал happy path: заполнение анкеты → подписание → открытие счёта → выпуск виртуальной карты

## Инструменты
Camunda Modeler / draw.io, нотация BPMN 2.0
