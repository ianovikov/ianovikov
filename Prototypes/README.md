# Прототипы экранов — Цифровой онбординг

## Что это
Прототипы ключевых экранов мобильного приложения для сценария цифрового онбординга, разработанные в Figma по итогам [BRD](../01-brd/BRD.md#17-прототипы-ключевых-экранов) и [Use Case диаграммы](../02-use-case).

## Экраны

### Экран 1. Старт регистрации
![Старт регистрации](./screen-01-start.png)
Клиент вводит номер телефона и даёт согласие на обработку персональных данных для получения OTP-кода. Есть альтернативный вход через Госуслуги.

### Экран 2. Выбор способа верификации
![Выбор способа верификации](./screen-02-verification-choice.png)
Клиент выбирает канал идентификации: через Госуслуги (рекомендуемый, ~2 мин) или по паспорту и селфи (~4 мин).

### Экран 3. Результат: счёт открыт
![Счёт открыт](./screen-03-success.png)
Финальный экран с подтверждением открытия счёта, реквизитами виртуальной карты «Мир» и персональным предложением по кешбэку.
