# OpenAPI спецификация — Digital Onboarding API

## Что это
OpenAPI 3.1 спецификация API для процесса цифрового онбординга. Покрывает три ключевых шага из BRD: регистрацию по номеру телефона (FR-01, FR-02), верификацию через ЕБС (FR-04) и открытие счёта с выпуском виртуальной карты.

## Эндпоинты
| Метод | Путь | Назначение |
|---|---|---|
| POST | `/registration/otp` | Отправка OTP-кода на телефон клиента |
| POST | `/verification/ebs` | Верификация личности через Единую биометрическую систему (не более 3 попыток — BR-08) |
| POST | `/accounts` | Открытие счёта и выпуск виртуальной карты |

Для каждого эндпоинта описаны примеры запросов/ответов и коды ошибок (лимиты OTP, превышение попыток верификации, недоступность ЕБС, отказ комплаенса).

## Инструменты
OpenAPI 3.1 / Swagger
