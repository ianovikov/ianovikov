# SQL Portfolio — Цифровой онбординг

## Что это
Интерактивная HTML-страница с ERD и 8 SQL-кейсами по данным цифрового онбординга. Запросы выполняются прямо в браузере на встроенной SQLite-базе (sql.js), результат — реальная таблица, а не картинка.

## Кейсы
1. **CASE WHEN + JOIN** — классификация заявок по уровню риска
2. **Агрегация по заявкам** — COUNT/AVG/MIN/MAX по статусам
3. **GROUP BY + CASE WHEN** — конверсия по каналам и методам верификации
4. **HAVING** — каналы верификации с процентом отказов выше 20%
5. **ORDER BY + WHERE IN** — заявки на ручную проверку и отклонённые, отсортированные по риску
6. **JOIN + LEFT JOIN** — клиенты с выданными продуктами
7. **CTE (WITH)** — заявки короче среднего времени прохождения
8. **Оконные функции** — RANK() и AVG() OVER (PARTITION BY) по каналам

## Как посмотреть
Открыть [`index.html`](./index.html) в браузере — база создаётся и все запросы выполняются автоматически при загрузке страницы.

## Инструменты
SQLite (sql.js), HTML/CSS/JS
